## 2. Mixamo 에서 받기 (사람이 한다)

1. <https://www.mixamo.com> — Adobe ID 로 로그인 (무료, 구독 불필요).
2. **Characters** 에서 실사 비율의 남성 캐릭터를 고른다. 옷이 단순한 것(민무늬 티셔츠·바지)이 물들이기 좋다. 예: "Ch36", "Ch46" 계열(이름은 사이트에서 확인).
3. **Animations** 에서 아래를 검색해 하나씩 다운로드한다. 설정: *Format FBX Binary · Skin With Skin(첫 번째 캐릭터 파일만) · 나머지는 Without Skin · 30 fps · Keyframe Reduction none*.
   **달리기·걷기·킥처럼 앞으로 나가는 동작은 오른쪽 패널의 "In Place" 를 켠다** — 안 켜면 캐릭터가 클립 안에서 2~3 m 전진했다 되돌아온다(2026-09-15 Ch38: run 2.5 m · kick 2.8 m). 못 켰어도 빌드 도구와 로더가 Hips 의 수평 이동을 지우니 게임은 되지만, 켜서 받은 쪽이 발 미끄러짐이 적다.

| 우리 이름 | Mixamo 검색어 (후보) |
|---|---|
| idle | "Idle" (Standing Idle) |
| walk | "Walking" |
| run | "Running" |
| sprint | "Sprint" / "Fast Run" |

| slide | "Soccer Tackle" / "Slide Tackle" |

| throw | "Throw In" / "Throw" |

4. 받은 파일을 저장소 밖 폴더(예: `C:\assets\mixamo\`)에 둔다. **저장소 `assets/` 에 넣지 않는다** (`.gitignore` 에 있다).

## 3. GLB 로 굽기 — `npm run char:build` (있다, 2026-09-15)

폴더 안 파일 이름이 곧 클립 이름이다: `character.fbx`(스킨 포함) + `idle.fbx` `walk.fbx` `run.fbx` `kick.fbx` … (Without Skin 권장 — With Skin 이어도 되지만 파일이 52 MB 씩이다).

**Mixamo 에서 받는 법 (화면 기준)**: Characters 탭에서 캐릭터를 고르고 오른쪽 **DOWNLOAD** → Format `FBX Binary`, Pose `T-pose` → 그 파일이 `character.fbx`. Animations 탭에서 검색(예: "Soccer") → 애니를 고르면 오른쪽에 미리보기 → **DOWNLOAD** → Format `FBX Binary`, Skin **Without Skin**, 30 fps, Keyframe Reduction none → 받은 파일을 `idle.fbx` 처럼 우리 이름으로 바꾼다. **자동으로는 못 받는다** — Adobe 로그인 세션이 필요하고 약관상 사용자가 직접 받아야 한다.
9/15 에 받은 것: Breathing Idle → `idle` · Fast Run → `run` · Soccer Pass → `pass` · Strike Foward Jog → `kick`. `Walking Left Turn` 은 회전 동작이라 뺐다(직진 **Walking** 을 받으면 `walk.fbx`). 더 받으면 좋은 것: Walking · Soccer Tackle(→ slide) · Soccer Trip(→ fall) · Goalkeeper Diving Save(→ dive_l/dive_r) · Throw In(→ throw) · Victory(→ celebrate).

```bash
npm run char:build -- C:\assets\mixamo
npm run char:build -- C:\assets\mixamo --out public/models/player.glb --char character
```

`tools/char/build.mjs` 가 하는 일:

1. `fbx2gltf`(npm 0.9.7, Facebook 공개 바이너리 — Blender 불필요)로 FBX 마다 GLB 를 임시 폴더에.
2. `@gltf-transform` 4.5 로 애니 GLB 들의 클립을 캐릭터 GLB 의 **뼈 이름으로**(`mixamorig:` 접두어 무시) 옮겨 붙인다. 클립 이름 = 파일 이름(소문자).
3. 노멀맵·AO 제거(`--keep-normal` 로 유지) · 메시 단순화(meshoptimizer, `--ratio 0.3` 기본) · 텍스처 `--tex 1024` 축소(pngjs·jpeg-js 순수 JS) · `dedup` · `prune` · `resample` · `quantize`(위치·법선·UV 만) → 저장.
4. 삼각형·클립·크기를 찍는다. 8 MB 를 넘으면 경고.

검증: three.js 예제 `Samba Dancing.fbx`(Mixamo 캐릭터+애니 한 파일)를 `character.fbx` 로 두고 돌리면 **2.6 MB · 55k 삼각형 · 스킨 2(관절 52) · 클립 53채널**이 나온다. 참고로 55k 는 너무 많다 — 실제 선수용 캐릭터는 12k 이하를 고른다.

Blender(무료)로도 같은 결과를 만들 수 있다: 캐릭터 FBX 를 열고 애니 FBX 들을 *Import → Animation only* 로 붙인 뒤 *Export glTF (Binary, +Y up)*.

## 4. 확인

1. `npm run dev` → 로비에서 ⚙ 설정 "선수 그래픽 = 실사" → 혼자 하기.
2. 콘솔에 `[char]` 경고가 없어야 한다(있으면 클립 이름·뼈 이름 문제).
   `node tools/char/inspect.mjs public/models/player.glb` — 클립 길이 · **Hips 이동 폭**(run·kick 의 x·z 가 0 에 가까워야 제자리) · 킥·패스의 차는 순간(초)을 찍는다.
   경기 중 콘솔에서 `__klo.renderer().rigs[0].mixer._actions` 로 가중치를 보고, 걷는 선수가 T포즈면 walk·run 이 같은 액션인지 의심한다.
3. 오른쪽 위 fps — 내장 GPU 에서 50 이상. 낮으면 설정에서 그림자 끄기 → 그래도 낮으면 모델 삼각형(목표 ≤ 12k)을 줄인다.
4. 유니폼 색 — 홈은 구단 색, 원정은 흰색, GK 는 별색. 피부가 물들면 `playerReal.ts tintTexture` 의 피부 판정을 캐릭터에 맞춘다.

## 5. 원칙 (DESIGN 7.1 · 개발계획 5장)

- 실존 선수 얼굴·피부색·실제 유니폼 디자인은 쓰지 않는다.
- 원본 FBX 는 저장소에 넣지 않는다 — 변환된 GLB 만.
- 찰흙 모드는 남긴다(저사양 PC · 파일을 못 받았을 때).
