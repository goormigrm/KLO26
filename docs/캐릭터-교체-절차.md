# 실사 캐릭터 교체 절차 (2026-09-15)

> 경기의 "선수 그래픽 — 실사" 는 `public/models/player.glb` 한 파일을 읽는다. 이 파일을 바꾸면 22명이 전부 바뀐다.
> 지금 들어 있는 것은 **three.js 예제의 Soldier**(Mixamo 캐릭터 · 헬멧 쓴 군인)로 파이프라인 검증용이다.
> 최종 인간 캐릭터는 **Mixamo 에서 직접 받아야** 한다 — Adobe ID 로그인이 필요해 자동화할 수 없다.

## 1. 파일 규약

| 항목 | 값 |
|---|---|
| 경로 | `public/models/player.glb` (GitHub Pages 에 그대로 올라간다 — **원본 FBX 는 올리지 않는다**) |
| 뼈대 | Mixamo 표준 (`mixamorigHips`, `mixamorigSpine`, `mixamorigSpine1`, `mixamorigLeftUpLeg`, `mixamorigRightUpLeg`, `mixamorigLeftArm`, `mixamorigRightArm`, `mixamorigHead` …). 이름에 `:` 가 있어도 된다 |
| 필수 클립 | `idle` · `walk` · `run` (대소문자 무관). 없으면 실사 모드가 실패하고 찰흙으로 남는다 |
| 있으면 쓰는 클립 (다음 단계) | `sprint` · `kick` · `pass` · `slide` · `fall` · `getup` · `dive_l` · `dive_r` · `catch` · `throw` · `celebrate` — `playerReal.ts` 가 절차적 덧씌우기 대신 클립을 쓰도록 이어 붙일 자리 |
| 크기 | 목표 ≤ 8 MB (Draco 또는 meshopt 압축) |
| 정면 | +Z (Mixamo 기본) · 단위 m · 발 아래 원점 |
| 재질 | 텍스처가 있으면 캔버스에서 피부색 픽셀은 남기고 나머지를 구단 색으로 물들인다. 텍스처가 없으면 재질 색을 구단 색으로 |

## 2. Mixamo 에서 받기 (사람이 한다)

1. <https://www.mixamo.com> — Adobe ID 로 로그인 (무료, 구독 불필요).
2. **Characters** 에서 실사 비율의 남성 캐릭터를 고른다. 옷이 단순한 것(민무늬 티셔츠·바지)이 물들이기 좋다. 예: "Ch36", "Ch46" 계열(이름은 사이트에서 확인).
3. **Animations** 에서 아래를 검색해 하나씩 다운로드한다. 설정: *Format FBX Binary · Skin With Skin(첫 번째 캐릭터 파일만) · 나머지는 Without Skin · 30 fps · Keyframe Reduction none*.

| 우리 이름 | Mixamo 검색어 (후보) |
|---|---|
| idle | "Idle" (Standing Idle) |
| walk | "Walking" |
| run | "Running" |
| sprint | "Sprint" / "Fast Run" |
| kick | "Soccer Kick" / "Strike" |
| pass | "Soccer Pass" |
| slide | "Soccer Tackle" / "Slide Tackle" |
| fall | "Soccer Trip" / "Falling" |
| getup | "Getting Up" / "Stand Up" |
| dive_l / dive_r | "Goalkeeper Diving Save" (좌·우 두 개, 없으면 하나를 미러) |
| catch | "Goalkeeper Catch" |
| throw | "Throw In" / "Throw" |
| celebrate | "Victory" / "Cheering" (둘) |

4. 받은 파일을 저장소 밖 폴더(예: `C:\assets\mixamo\`)에 둔다. **저장소 `assets/` 에 넣지 않는다** (`.gitignore` 에 있다).

## 3. GLB 로 굽기 (도구 — P1-b 에서 만든다)

```bash
npm run char:build -- C:\assets\mixamo
```

`tools/char/build.mjs` 가 할 일:

1. `fbx2gltf`(npm, Facebook 공개 바이너리)로 캐릭터 FBX 와 애니 FBX 를 각각 GLB 로.
2. `@gltf-transform`으로 애니 GLB 들의 클립을 캐릭터 GLB 의 뼈대에 합치고(뼈 이름으로 리타게팅), 클립 이름을 위 표의 우리 이름으로 바꾼다.
3. `dedup` · `prune` · `resample` · `meshopt` 압축 → `public/models/player.glb`.
4. 삼각형·클립 목록·크기를 찍어 준다.

도구가 생기기 전이라도 Blender(무료)로 같은 결과를 만들 수 있다: 캐릭터 FBX 를 열고 애니 FBX 들을 *Import → Animation only* 로 붙인 뒤 *Export glTF (Binary, +Y up, Compression)*.

## 4. 확인

1. `npm run dev` → 로비에서 ⚙ 설정 "선수 그래픽 = 실사" → 혼자 하기.
2. 콘솔에 `[char]` 경고가 없어야 한다(있으면 클립 이름·뼈 이름 문제).
3. 오른쪽 위 fps — 내장 GPU 에서 50 이상. 낮으면 설정에서 그림자 끄기 → 그래도 낮으면 모델 삼각형(목표 ≤ 12k)을 줄인다.
4. 유니폼 색 — 홈은 구단 색, 원정은 흰색, GK 는 별색. 피부가 물들면 `playerReal.ts tintTexture` 의 피부 판정을 캐릭터에 맞춘다.

## 5. 원칙 (DESIGN 7.1 · 개발계획 5장)

- 실존 선수 얼굴·피부색·실제 유니폼 디자인은 쓰지 않는다.
- 원본 FBX 는 저장소에 넣지 않는다 — 변환된 GLB 만.
- 찰흙 모드는 남긴다(저사양 PC · 파일을 못 받았을 때).
